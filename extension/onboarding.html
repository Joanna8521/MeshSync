⚡ Mesh Sync 裝好了！

還差兩步就能開始自動收藏 AI 討論脈絡。

1連接你自己的 Google 帳號

點瀏覽器右上角的 Mesh Sync 圖示 → 按「連接 Google」。 檔案只會寫進你自己的雲端硬碟，權限範圍僅限這個擴充功能自己建立的檔案（drive.file）。

如果按下去出現「bad client id」，代表 manifest.json 裡還沒填入你的 OAuth client ID——請照 README 的「OAuth 設定」一節做一次（約五分鐘，只需做一次）。

2把這段 Prompt 貼進 AI 的個人化設定

AI 不會自己輸出 [CONTEXT] 標記——是這段指示叫它輸出的。貼一次，之後每場對話都有效：

當我說「記錄脈絡」或這段討論產生重要結論時，
請在回覆的最後面輸出這個區塊（原樣輸出，不要解釋）：
[CONTEXT]
{"summary":"一句話總結","key_points":["重點1","重點2"],"decision":"做了什麼決定"}
[/CONTEXT]
平台貼在哪裡
ChatGPT設定 → 個人化 → 自訂指令（「你希望 ChatGPT 如何回應」欄位）
ClaudeSettings → Profile 的偏好欄位，或每個 Project 的自訂指示
Gemini設定 → Saved Info（儲存的資訊）

平常怎麼用

方式一（圈選）：在對話頁面選取重要段落，旁邊會浮出「⚡ 存入脈絡」按鈕，按一下就寫入。

方式二（標記）：對 AI 說「記錄脈絡」，它會在回覆結尾輸出 [CONTEXT] 區塊，右下角跳出確認卡，按「寫入」即可。

同一場對話不管存幾次，都累加在同一份 Google Doc 裡，檔名自動帶日期＋主題＋平台，文件底部有原始討論的連結。用 popup 切換「客戶」，寫入目標資料夾會跟著切換。
